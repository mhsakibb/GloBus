\chapter{IMPLEMENTATION \& SYSTEM FEATURES}
\section{User Section}
In the GloBus platform, we have implemented role-based access control (RBAC) to ensure security and proper functionality separation. We have three primary kinds of users interacting with the system:
\begin{itemize}
    \item \textbf{Guest User:} Unauthenticated users who can browse products, search, and view categories, but must log in to checkout.
    \item \textbf{Customer:} Authenticated users who can manage their cart, save wishlists, checkout via SSLCommerz, and track their order history.
    \item \textbf{Administrator:} Highly privileged users who access the secure admin panel to manage products, orders, users, and view platform statistics.
\end{itemize}
